# 공통 문서

팀 사이에 주고받는 약속(API 형식, 데이터 구조)은 여기에 둡니다. 각 파트 내부 설명은 해당 폴더의 README에 둡니다.

| 문서 | 내용 | 담당 | 상태 |
| --- | --- | --- | --- |
| [api/ocr-api.md](api/ocr-api.md) | OCR 서버 ↔ 백엔드 API | OCR · 백엔드 | 초안 (에러 코드 등 확정 필요) |
| api/backend-api.md | 백엔드 ↔ 프론트 API | 백엔드 · 프론트 | 작성 예정 |
| architecture.md | 시스템 구성도, 사용자 흐름도, DB 구조 | 백엔드 | 작성 예정 (현재 eraser 다이어그램) |

계약 문서를 바꾸는 PR은 양쪽 담당이 모두 리뷰합니다.
