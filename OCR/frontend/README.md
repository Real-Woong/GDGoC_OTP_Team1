# 프론트엔드

> 프론트 팀이 작성합니다. 아래는 지금까지 정해진 내용만 적어 둔 초안입니다.

- **기술:** 모바일 웹 PWA, Next.js (구성도 기준)
- **역할:** 소개·업로드·확인·점검 결과·할 일 화면 (사용자 흐름도 기준)
- **OCR 결과 확인 화면에서 쓰는 값:** `status: needs_review` 필드 강조, `join_date` 확인, `unmapped_items` 질문, `hints` 안내, 에러 코드별 화면 분기 → [OCR API 명세](../docs/api/ocr-api.md)

프론트는 OCR 서버를 직접 호출하지 않고 백엔드를 거칩니다.
